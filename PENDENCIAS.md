# Site Fausto de Oliveira — portfólio

Projeto de demonstração (portfólio), derivado do site do Nathan Lorena. Dados fictícios:

- **CRN 00000** e **+350 pacientes** são valores de exemplo.
- `const WHATSAPP = ""` no `index.html`: enquanto vazio, os botões rolam até a seção de contato.
- Link do Instagram no rodapé aponta para `https://www.instagram.com/` genérico.
- Monograma "FO" (`assets/logo-monograma-hd.png`) gerado por script, na mesma linguagem geométrica do logo original.
- Recorte da foto (`assets/fausto-recorte.webp`) feito com rembg a partir de `_originais/fausto-original.png`.
